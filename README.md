# AtHomeNailSalon

Two deliberately different website concepts for a fictional solo nail artist working from a private home studio.

## Concept 1 — Clara Studio
Quiet-luxury / editorial direction. Soft, premium and reassuring, with strong focus on clear pricing, home-studio trust, service guidance, work, reviews, FAQs and booking.

Open: `/concept-one/`

## Concept 2 — Clara Studios Premium Demo
Editorial, quiet-luxury direction based on The Website Mill social mockups. Includes responsive client pages, dynamic future availability, slot locking, a four-step booking journey, a downloadable calendar event and a polished owner dashboard that updates from completed bookings in the same browser.

Open: `/concept-two/`

## Root page
The root `index.html` acts as a concept chooser so both directions can live in one demo deployment.

## Notes
- Fictional business names, reviews and example prices.
- Nail photography is loaded from fixed Unsplash image URLs for demo purposes.
- Responsive layouts include mobile booking CTAs and simplified navigation.
- The interactive demo uses browser storage. Production calendar/email integrations and multi-device bookings would require a shared database and authenticated server-side services.
